## Дополнительные материалы

**1.** Как было сказано в уроке, `arr[i]` -- это просто более удобный способ записи для `*(arr + i)`. Такие конструкции называют =синтаксическим сахаром=. Мы как бы подсластили жизнь программиста тем, что придумали более простую запись, которая позволят не мучиться со сложным синтаксисом, а с точки зрения компилятора обозначает тоже самое, что и сложная запись.

Отсюда же вытекает нумерация элементов массива с нуля. `arr[i]` означает "взять адрес начала и сдвинуться на `i` элементов". Для нулевого элемента сдвиг равен нулю: `*(arr + 0)`, то есть `*arr`.

**2.** Спецификатор `%p` по стандарту ждёт нетипизированный адрес (тип `void *`), поэтому было бы более корректно перед печатью явно преобразовывать указатель: `(void *) &arr[i]`. Я так не делал, чтобы не загромождать код.

**3.** Оператор `sizeof` возвращает значение типа `size_t`, для него в `printf` правильнее было бы использовать спецификатор `%zu`, а не `%d`.

**4.** Имя массива -- не обычная переменная-указатель. Например, ей в отличие от обычного указателя нельзя ничего присвоить. 

Например, следующая программа не скомпилируется.

```c
#include <stdio.h>
#define ARR_SIZE 5

int main(void)
{
        int grades[ARR_SIZE] = {1, 4, 9, 82, 777};
        int *p = grades;  // создаём обычный указатель, который указывает на начало массива 

        p += 1;           // можно
        grades += 1;      // ошибка

        p = NULL;         // можно
        grades = NULL;    // ошибка

        return 0;
}
```
