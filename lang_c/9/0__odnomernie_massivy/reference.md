## Дополнительные материалы

**1.** Формально в языке Си массив -- это простейший =производный тип данных=.

Например, пусть массив `digits` объявлен следующим образом:
```c
int digits[10];
```

Объект `digits` здесь имеет тип `int[10]` (массив из `10` элементов типа `int`). При этом, число `10` -- это часть этого типа данных.

Поэтому у массива `numbers`, объявленного как `int numbers[50];`, уже другой тип данных -- `int[50]`.

Для любого из известных нам типов данных, можно на его основе создать производный тип данных массив из `N` элементов этого типа.

**2.** Если мы явно инициализируем массив при объявлении, то число в квадратных скобках можно не писать -- компилятор посчитает сам.

Т.е. массив `grades` в нашем примере можно было объявить следующим образом:
```c
int grades[] = {1, 4, 9, 82, 777};
```
