### Исследовательские задачи для хакеров

- Размер массивов, которые можно создать указанным в уроке способом, ограничен размером =стека=. Стек -- это небольшая область оперативной памяти, которая выделяется нашей программе при запуске. Именно в этой области выделяется память под локальные переменные и массивы, объявленные в функции `main` и в других функциях нашей программы. 

Т.к. размер стека ограничен, то мы не можем создать указанным образом массив произвольного размера. Если же мы всё-таки попробуем создать очень-очень большой массив, то программа сломается.

Подберите минимальный размер массива, который сломает следующую программу в вашей системе.

```c
#include <stdio.h>

int main(void)
{
        int grades[100000] = {0};

        for (int i = 0; i < 1000; i++) {
                printf("%d ", grades[i]);
        }
        printf("\n");

        return(0);
}
```

Вычислив размер массива и зная размер памяти, который занимает переменная типа `int` (каждый элемент массива), вычислите примерный размер стека. О результатах ваших исследований напишите в комментариях к уроку.
