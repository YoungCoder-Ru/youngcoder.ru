### Исследовательские задачи для хакеров

**1.** Ниже записан другой, более сишный, вариант функции `clear_stdin`.

```c
void clear_stdin(void)
{
        int tmp;

        while ((tmp = getchar()) != '\n' && tmp != EOF) {
                ;
        }
}
```

Разберитесь самостоятельно, как он работает. Зачем присваивание стоит прямо в условии цикла и что означает пустое тело `;`? Есть ли здесь побочный эффект? Совпадает ли результат с вариантом из урока?

**2.** Спецификатор `%s` читает только одно слово. Но у `scanf` есть и другие спецификаторы, с помощью которых можно считать все символы из потока до перевода строки, включая пробелы. Пример ниже.

```c
char line[11] = "..........";
int result;

result = scanf("%10[^\n]", line);
printf("%d |%s|\n", result, line);
```

Массив заранее заполнен `.`, чтобы было видно, записала ли `scanf` в него что-нибудь. 

Разберитесь, как работает этот спецификатор. Проверьте на входной строке `Gill Bytes`, что окажется в массиве и что останется в `stdin`. 

Запустите программу ещё раз и сразу нажмите `Enter`. Посмотрите, что вернёт `scanf`. Записала ли она в массив нуль-символ? 

Запустите программу со строкой длиннее `10` символов. Проверьте, что будет, если убрать `10` и оставить `%[^\n]`. Что попало в массив? Что осталось в потоке ввода? Было ли предупреждение от компилятора?

**3.** Скомпилируйте и запустите следующую программу. Получилось ли? Предупреждает ли компилятор? Что происходит при запуске?

```c
#include <stdio.h>

int main(void)
{
        char name[] = "Gill";
        char *p = "Gill";
        puts(name);
        puts(p);

        printf("Change name:\n");
        name[0] = 'Z';
        puts(name);


        printf("\nChange p:\n");
        p[0] = 'B';
        puts(p);

        return 0;
}
```

Разберитесь, в чём разница между этими двумя вариантами объявлений и почему программа работает таким образом.
