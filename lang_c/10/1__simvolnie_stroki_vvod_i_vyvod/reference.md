## Дополнительные материалы

**1.** У функции `fgets` есть упрощённый аналог, который читает только из стандартного потока ввода, -- функция `gets`. В уроке уже разобрано, почему её не стоит использовать: она не проверяет длину строки и, начиная со стандарта C11, исключена из языка. Похожая пара есть и на выводе. У функции `puts` есть аналог `fputs`, которому можно явно указать поток:

```c
int fputs(const char *s, FILE *stream);
```

В отличие от `puts`, функция `fputs` не добавляет в конец вывода символ `\n`.

**2.** Обратите внимание на тип третьего аргумента в прототипе функции `fgets`:

```c
char *fgets(char *s, int size, FILE *stream);
```

`FILE` -- это тип, которым в стандартной библиотеке описывается поток ввода или вывода. Как он устроен внутри, нас не особо волнует. Важно другое: словечко `stdin`, используемое нами ранее, это не какое-то волшебное слово, а выражение типа `FILE *`, то есть указатель на объект, описывающий стандартный поток ввода. Точно так же устроены `stdout` и `stderr`.

**3.** В функции `get_string` (Листинг 19) обрабатываются два исхода работы `fgets`. Но есть и третий вариант: функция `fgets` не прочитала ни одного символа. В таком случае она возвращает значение `NULL` и не записывает в массив нуль-символ. Это может случиться, если данные в потоке уже закончились или при ошибке чтения. Если это произойдёт, то функция `get_newline_position` начнёт читать массив, в котором нет нуль-символа, а это неопределённое поведение.

Поэтому было бы правильно проверить результат `fgets` до того, как начать работать с массивом:

```c
void get_string(char *str, int max_size)
{
        if (fgets(str, max_size, stdin) == NULL) {
                str[0] = '\0';
                return;
        }

        int newline_position = get_newline_position(str);
        if (newline_position >= 0) {
                str[newline_position] = '\0';
        } else {
                discard_line();
        }
}
```

Теперь функция будет обрабатывать все три варианта. Если `fgets` вернёт `NULL`, наша функция вернёт пустую строку.
