### Исследовательские задачи для хакеров

**1.** Для четырёх из пяти разобранных в уроке функций есть варианты с ограничением количества обрабатываемых символов: `strncat`, `strncmp`, `strncpy` и `strnlen`. Изучите самостоятельно, как работают эти функции. Функция `strnlen` появилась совсем недавно, поэтому ваш компилятор может её не поддерживать.

**2.** (Листинг 7) Попробуйте, добавляя символы в строки `str2` или `str3`, добиться того, чтобы программа завершалась с ошибкой.

**3.** Ниже представлена программа из Листинга 7, но с дополнительной переменной `a`. Запустите её и убедитесь, что она корректно работает.

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
        // объявляем три строки
        int a = 5;
        char str1[20] = "Peace! ";
        char str2[] = "Labor! ";
        char str3[] = "May!";

        // выводим строки на экран
        printf("str1: %s\n", str1);
        printf("str2: %s\n", str2);
        printf("str3: %s\n\n", str3);

        // присоединяем к первой строке вторую
        strcat(str1, str2);
        // теперь str1 = "Peace! Labor! "

        // присоединяем к первой строке третью
        strcat(str1, str3);
        // теперь str1 = "Peace! Labor! May!"

        // выводим на экран строку str1 и её длину
        printf("string: %s\nlength: %d\n", str1, (int)strlen(str1));
        printf("%d\n", a);
        
        return 0;
}
```

Затем измените размер массива `str1` с `20` на `18`. Теперь при запуске программы вы скорее всего увидите, что в переменной `a` значение меняется на `0`. Разберитесь, почему это происходит. Рекомендую вам проследить за адресами по которым расположены переменные `a`, `str1`, `str2` и `str3`. Своё объяснение, желательно с картинками, присылайте в комментарии к этому уроку.
